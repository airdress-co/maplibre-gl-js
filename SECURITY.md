# Security

A vulnerability in this fork's own patches: report it to
security@airdress.co, or privately through this repository's security
advisories. Please do not open a public issue.

A vulnerability in MapLibre GL JS itself: report it to upstream, as
[maplibre/maplibre-gl-js's security policy](https://github.com/maplibre/maplibre-gl-js/security/policy)
describes. This fork takes upstream's security fixes within days of their
release.
